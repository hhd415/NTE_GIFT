# 🎁 异环最优礼物方案计算器

> 🌐 在线访问：https://hhd415.github.io/NTE_GIFT/

一个纯前端静态网页工具，帮你找到《异环》全角色的**最优礼物方案**，避免凭直觉送礼导致的多花方斯。

## ✨ 功能

- **二维图展示法**：直观对比不同角色的礼物档位与花费
- **补礼物计算**：按当前好感度计算还差多少礼物（含 8 级以下 +5% 好感加成）
- **混搭礼物最优法**：允许同一角色混搭 100 / 200 / 400 档礼物，通过帕累托最优曲线找出「平均天数 — 人均方斯」的最优方案
- **地点整合与排序**：方便按商店地点批量购买

## 🚀 使用方法

无需安装任何依赖，任选其一：

1. 直接用浏览器打开 `index.html`
2. 或在项目目录下启动一个本地服务器：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx http-server
```

然后访问 `http://localhost:8000`。

## 🧪 运行测试

```bash
# mixed.js 算法单元测试
node test-mixed.js

# minCount 参数对计算量的性能基准
node bench-min.js
```
